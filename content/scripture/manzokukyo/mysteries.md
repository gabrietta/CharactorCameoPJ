# 謎の登録簿

教典の中で、答えを書かないまま置いてある謎の一覧。怖さの7割を支える大事な仕掛けなので、共同執筆者は次を守る。

- 登録された謎の**答えを本文に書かない**。解くかどうかは編纂責任者が決める。
- ほのめかし、新しい手がかり、別の章からの言及は歓迎。追加したら「言及箇所」に書き足す。
- 手がかり同士が矛盾してもよい（伝承の食い違いとして扱う）。ただし、答えを一つに絞り込んでしまう手がかりは避ける。
- 新しい謎を作ったら、ここに登録する。
- 作者側の想定解がある場合も、このファイルには書かない。

## 主要な謎（D-25、仮決定）

教典全体を貫く謎を十に絞り、下の表の謎はすべて、いずれかの「枝」として扱う。新しい謎を足すときは、必ずどれかの主要な謎の枝にする（表の「主要な謎」の列に書く）。主要な謎そのものを増やす・減らすのは、編纂責任者が決める。

| 主要な謎 | 中身 |
|---|---|
| 四分目と時の外 | 三分の外にある時。四分目、四つ目、止まった時計、十三月、延べられし二日 |
| 記録室 | 記録室とは何か。消しゴムの列、写しと原本、書き留められる言葉 |
| 完了者と「満足」の意味 | 満ち足りた者のゆくえと、変わってしまった「満足」という語 |
| 名簿と名 | 名簿の最初の欄、名簿の名、薄くなる名、A欄 |
| 空席 | Aの椅子、空席の英字、温かい席と冷たい席、隣のもう一人 |
| MEDと霧の国 | 教祖が追う影と、教祖の生まれた霧の国 |
| 書かれないこと | この書を編んだ者、黒塗り、剥がされた紙、語られない答え |
| 帳のかなたの声 | 帳のかなた、後ろの声、台本にない問い、自分に似た声 |
| 映るものと、一つ多いもの | 鏡・丼の底・暗い画面に遅れて映るもの。数が一つ多いもの |
| 枕辺と帰り道 | 枕辺に並ぶ欠片、窪み、夜、違う家、知らない路地 |
